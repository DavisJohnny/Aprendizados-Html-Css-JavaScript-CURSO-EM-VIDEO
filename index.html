O desenvolvimento de paginas web HTML 5

A linguagem HTML 5 é conhecida por ser uma linguagem semântica, de acordo com o Google a paralavra semântica significa:

A palavra semântica vem do grego semantiké (que significa "relativo aos signos" ou "significativo") e refere-se à área da linguística que estuda o significado e o sentido das palavras, das frases e dos textos

Trazendo para nossa realidade do curso o que isso quer dizer ?

Há muitas formas de inserir tags e comandos para dar formas aos nossos textos, porem algumas tem significados e outras não. exemplos a seguir:

    Tags não semântica (Sem significado)

    1. ITÁLICO <I>

    2. NEGRITO <B>

    Tags semânticas

    1. CITAÇÕES <CITE>

    2. STRONG <STRONG>

Vôce consegue ver que faz a mesma edição no texto porém não significa a mesma coisa. Para editar o texto usamos o CSS

Se você como eu está em busca de aprender a criar sites completos, essas são as primeiras coisas que você irá aprender, a base sólida do html 5.
