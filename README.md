# 🚀 Meus Primeiros Passos em HTML5

Este repositório marca o início da minha jornada no desenvolvimento web! Este é o *meu primeiro código em HTML*, desenvolvido durante os meus estudos práticos no curso de HTML, CSS e JavaScript do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor Gustavo Guanabara.

## 🛠️ O que pratiquei neste projeto:
* Estrutura básica de um documento HTML5 (DOCTYPE, html, head, body).
* Uso de títulos e hierarquia (h1, h2, h3).
* Formatação de textos e aplicação de tags de destaque (mark, cite, strong, blockquote).
* Criação de listas (ul) e inserção de links externos utilizando atributos como target="_blank".
